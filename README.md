# Caring Hearts

A community-driven platform dedicated to connecting donors with meaningful causes.
**Caring Hearts Social** provides a transparent way to view upcoming events, set and track donation goals, and share the real-world impact of every contribution.

## 🌐 Live Demo
Visit the site at: [https://yaakydd.github.io/Caring-Hearts/]

## ✨ Features

* **📅 Upcoming Events:** Stay informed about community gatherings, fundraisers, and volunteer opportunities.
* **🎯 Donation Goals:** Set specific financial targets for various causes.
* **📊 Progress Tracking:** Real-time visual tracking of donation milestones to show how close a goal is to being met.
* **📖 Donation Stories:** Read personal accounts from donors about why they give.
* **🌟 Impact Stories:** See the tangible results of donations through success stories and community testimonials.

## 📂 Project Structure

The project is built with a clean, lightweight frontend architecture:

```text
├── assets/             # Images, icons, and brand graphics
├── index.html          # Main entry point and website structure
├── caring.css          # Custom styling and layout definitions
├── script.js           # Interactive features and donation tracking logic
├── LICENSE             # Project licensing information
└── README.md           # Project documentation
```
